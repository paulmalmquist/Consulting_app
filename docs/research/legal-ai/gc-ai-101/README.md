## Why we keep this

Winston Legal's "AI behavior rules" and review-finding schema directly mirror the framework taught in this class:
- Treat AI like a smart, overeager intern — context is king.
- Always specify what you're handing over, the action, the format, and the audience.
- Force structured outputs (status / risk_level / evidence_quote) instead of loose prose.
- Use color/severity ratings (red/yellow/green ≈ deal-breaker / issue / acceptable).
- System prompt = standing legal-ops rules; user prompt = per-matter instruction.

The class confirmed the design thesis: **the AI does the prep, the attorney owns the judgment.** Keep this folder as the canonical reference for prompt language, evaluation rubrics, and the GC AI competitive baseline.
