# Marketing / Domain Routing — Design Adaptation

## Purpose in the design system

The marketing site is a light-mode, outward-facing surface. It is the opposite of the internal operator surfaces. It must communicate trust, sophistication, and capability to potential clients and investors. It is not a dashboard — it is a conversation starter.

## Accent choices
- Primary: `--nv-purple-400` (brand)
- CTAs: purple with high contrast
- No cyberpunk accents on marketing (save them for the product surfaces)
- Testimonial / social proof: warm neutral

## Light mode
Marketing is the one surface in the platform that uses light mode. Background is near-white. Text is near-black. Purple is the primary accent.

## Density
Low. Marketing pages should breathe. Headlines need space. Long blocks of body text should be broken up.

## Component emphasis
- Hero section: one clear headline, one subheadline, one CTA
- Industry pages: lead with a problem statement, not a feature list
- Proof/case studies: quantified outcomes first, product explanation second
- AI concierge: prominent input with a welcoming prompt, not a small chat button

## What this environment must NOT do
- Use dark shell on the marketing site (light mode only)
- Mix internal-surface visual language with marketing copy
- Show technical architecture diagrams to a non-technical audience
- Use more than one primary CTA per page section
