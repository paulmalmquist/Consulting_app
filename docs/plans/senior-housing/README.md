# Senior Housing / Healthcare Real Estate Analytics

**Status:** Draft  
**Last updated:** 2026-05-16

## Purpose

Senior Housing is a healthcare real estate analytics environment serving senior living operators, REITs, and investors. It tracks occupancy, NOI, revenue per unit, census trends, operator performance, and portfolio-level KPIs for senior housing assets. It is a vertical variant of the REPE environment with healthcare-specific metrics.
